# Smart Expense Tracker

## Overview

Smart Expense Tracker is a full-stack web application built using the MERN Stack that enables users to securely manage their personal finances. The application provides secure authentication, transaction management, financial summaries, and interactive dashboards for tracking income and expenses.

## Features

* Secure user registration and login using JWT Authentication
* Password encryption using bcrypt
* Add, update, and delete income transactions
* Add, update, and delete expense transactions
* Categorize income and expense records
* Interactive dashboard with visual representation of income and expenses
* Income vs. Expense comparison charts
* Display total income, total expenses, and current balance
* Responsive user interface
* Secure data storage using MongoDB

## Tech Stack

* MongoDB
* Express.js
* React.js
* Node.js
* JWT Authentication
* bcrypt
